## 1. 项目是什么

- **MD Viewer**：Electron + React 19 + TypeScript + Vite 的 **Markdown 预览器（不是编辑器）**。预览优先；v2.1 起才加了"可选编辑模式"，但定位仍是预览/交付工具。
- 仓库：`github.com/wj2929/md-viewer`。
- **单人自用**：作者本人是唯一用户兼唯一测试者。**无遥测、无线上反馈渠道**——所有 bug 都靠作者手动复现，没有用户日志可查。
- 支持多种图表：Mermaid / ECharts / Graphviz / DrawIO / Excalidraw / Markmap / Infographic / PlantUML / KaTeX（v2.2 又扩了 Vega-Lite / D2 / BPMN / WaveDrom / C4-PlantUML / Structurizr / Plotly / DBML / AntV G6 / Kroki）。
- 导出 HTML / PDF / DOCX。其中 **DOCX 走独立服务 `md-viewer-docx-service`**（同级目录 `../md-viewer-docx-service`，FastAPI + python-docx，负责图表截图 + Word 模板转换）。

## 3. v2.6.0 方向：原案 vs 评审结论

**原案主题**："导出交付增强与质量预检"。P0 含：① 导出前预检 GUI ② 导出结果审查 ③ `ExportVisualAsset` 图表统一尺寸模型 ④ DOCX 服务状态 ⑤ 导出配置记忆 ⑥ 回归基线。

**评审结论（已与作者达成一致）**：
- **方向对**：作者确实是重度导出用户，导出交付质量是真痛点。
- **但原案像给 SaaS 团队写的，对单人自用工具偏过度工程**。下列重型设计**先不做**：`ExportVisualAsset` 统一抽象、预检 GUI 平台化、双仓库 warning schema 协议。
- **平台能力长期慢慢做，但顺序必须"从修 bug 里长出来"，而不是先建抽象**。
- 原 roadmap 自身还有矛盾，接手时别照抄：
  - **P0 过载**（6 大块全压 P0）。
  - **实施顺序与风险表自相矛盾**：风险表说要先固化回归基线，却把它排到 P0 第 6 位。
  - **非目标与 P0 打架**：非目标说"不做项目健康扫描"，P0 预检却要查锚点/链接有效性。

## 5. 现在的唯一焦点

作者最堵心的是 **"图表导出偶尔异常"**。注意"**偶尔**"= 间歇性 bug。

- **第一目标不是修，而是先把它稳定复现 + 可观测。** 没有稳定复现，任何"修好了"都是赌运气。
- **核心理念**：平台能力**从修 bug 里长出来**——每修一个真实 bug，就顺手沉淀"可观测 + 校验 + 回归"三件套，而不是先去建大抽象。

## 6. 第一刀：从 Mermaid 开刀

**为什么是 Mermaid**：
- 出镜率最高、历史包袱最重。两条历史需在 CHANGELOG 核实：
  - **Mermaid 串行渲染**：`md-viewer/CHANGELOG.md` 已确认 = **v1.5.3**（`queueMermaidRender`）。✅
  - **strict 安全模式**：CHANGELOG 已确认在 **v1.3.5** 引入。✅
  - ⚠️ **"strict/loose + DOMPurify 冲突 → 改成 loose + `htmlLabels:true`"**：**两个 CHANGELOG 都查不到 "loose" / "htmlLabels" 字样**，只记录了 strict。这条修复来自项目记忆笔记（MEMORY），**未在任何 CHANGELOG 标注版本**——接手者必须**在代码里核实当前真实 `securityLevel`**，不要当成已发布特性引用版本号。
- Mermaid 是**"模板型"异步 SVG 图表**，做出来的脚手架可复用到 Graphviz / DrawIO / PlantUML。
- ⚠️ **ECharts / Excalidraw 是特例**（响应式、无固定 intrinsic 尺寸），**不要先碰**。

**"做完"的标准 = 跑通脚手架四件套**：
1. **确定性 ready 检测**：检测 SVG 真有内容（有 children / 有 bbox），**不用 `setTimeout` 瞎猜**。
2. **结构化留痕**：每个图表打 log —— 类型 / 是否渲染完 / intrinsic 尺寸 / 输出尺寸 / 耗时 / 产物是否存在。
3. **产物校验**：0 字节 / 尺寸为 0 / 纯白图 → 触发重试或 warning。
4. **回归 fixture**：把这次的复现样本固化成 fixture。
