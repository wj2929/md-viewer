## 3. 导出回归基线（核心安全网，已落地）

## 6. DOCX 漏源码修复（docx-service，已完成并端到端验证）

**精确根因（比"generator.py 的锅"更准）**：`generator.py` 只是忠实把它拿到的 markdown 建档——`parse_markdown`（`generator.py:220`）见到任何 ```围栏 就当 `CODE_BLOCK`(源码) 渲染。真正漏源码的是**上游没把"失败的图表围栏"换掉**：
- **CLI 路径 `/convert-source`**：`main.py:_replace_full_fidelity_chart_blocks` **只把"渲染出图片的"围栏**换成 `![](mdv__chart__…)`，失败的围栏原样留下。
- **GUI 路径 `/convert`**：客户端送来的 `md = req.markdown` 里，失败图表也是客户端留的源码围栏。
- 两条路最终都汇到 `generate_docx_from_content(md)` → 残留围栏变 CODE_BLOCK → 漏。

**修法（服务端安全网，一处堵两路 + defense-in-depth）**：`md-viewer-docx-service/app/main.py` 新增
`_neutralize_unrendered_chart_blocks(md)`：在两个 handler 调 `generate_docx_from_content` **之前**，把"所有渲染轮次后仍残留的图表语言围栏"统一换成中性占位 `[图表未渲染]`。
- **A 类**（docx 已支持但渲染失败，如中文 mermaid sankey）：复用 `FULL_FIDELITY_FENCE_PATTERN` + `FULL_FIDELITY_LANGUAGE_TYPES` 识别。
- **B 类**（docx 不渲染的图表语言）：新增 `UNSUPPORTED_CHART_FENCE_LANGUAGES`（kroki/antv-g6/dbml/plotly/structurizr 及别名，来源 md-viewer `builtin.ts`，**新增图表类型需同步**）。
- **只碰图表语言围栏**，绝不动 ```python/```text/```bash 等正常代码块，也不动 `![](mdv__chart__…)` 图片占位。
- 观测：响应加 `X-Charts-Neutralized` 头；count>0 时追加 warning「N 个图表未能渲染，已用占位符替代」（W1 诚实化，CLI/GUI 都能看见）。

**改动文件（docx-service，未提交）**：`app/main.py`（常量 + `_neutralize_unrendered_chart_blocks` + 两 handler 接入 + 2 个响应头）；`tests/test_chart_neutralization.py`（**新增 24 测**：纯函数 A/B/边界/占位/多围栏偏移 + `/convert-source` 与 `/convert` 集成）。

**验证（五重）**：
- pytest：新增 24/24 ✅；**全量 325/325 ✅**（301 旧 + 24 新，零回归）。
- **真实 CLI 导出**（leak-test.md：成功英文 mermaid + 中文 sankey + kroki + python 边界 → DOCX 解包 document.xml）：图表源码 `SANKEYLEAK`/`sankey-beta`/`KROKI机密源码LEAK`/`[A]->[B]` **全无残留**；`图表未渲染` 占位出现 **2 次**；`image1.png` 成功图在；`PYTHON_KEEPME` 真实代码**保留零误伤**；renderStatus=partial、CLI 收到中性化 warning。
- 导出回归基线（`MD_VIEWER_DOCX_SERVICE_URL=… node scripts/export-baseline.mjs`，含 DOCX）：见运行记录。

**docx-service 关键文件**：`app/main.py`（两 handler `/convert` `/convert-source` + 识别常量 + 安全网）、`app/generator.py`（`parse_markdown` 建档，**忠实渲染、不是 bug 点**）、`app/full_fidelity_renderer.py`（调 renderer CLI，`enabledRenderers` 不含 B 类）、`app/image_injector.py`（占位→图片注入）、`renderers/mdv-renderer-cli.mjs`（薄加载器）。
