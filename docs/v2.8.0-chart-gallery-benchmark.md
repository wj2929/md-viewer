# v2.8.0 图表示例单文件性能实测

> 日期：2026-09-04。此基准只用于决定内置案例包的稳定分页配置，不进入默认 E2E 或发布门禁。

## 方法

- 从 885 个 positive catalog 条目生成“每 renderer 一个 Markdown”的 19 个候选页；负例、压力和 infra 不参与。
- Electron BrowserWindow 保持隐藏；每页预热 1 次，再重复挂载 5 次。
- PlantUML/C4/Kroki 使用本地 mock 响应，不依赖公网，也不把性能结果混入网络波动。
- 记录最后一次 DOM 变化前的 ready 时间、Long Task、16ms 事件循环探针、DOM/SVG/canvas 数和 renderer 进程内存采样；ready 时间扣除用于确认稳定的 700ms 静默窗口及 100ms 采样等待。
- 告警线：median ready > 2s、P95 > 4s、单次 Long Task > 200ms、平均累计 Long Task > 500ms、最大 event-loop lag > 250ms、正向内存增量 > 150MB 或 DOM > 50,000。

手动运行：

```bash
npm run test:e2e:chart-benchmark
```

固定分页复测可使用：

```bash
MD_VIEWER_CHART_BENCHMARK=1 \
MD_VIEWER_CHART_BENCHMARK_MODE=fixed \
MD_VIEWER_CHART_BENCHMARK_RENDERERS=vega-lite,infographic,drawio,wavedrom \
npx playwright test e2e/chart-gallery-benchmark.spec.ts
```

## 两轮单文件结果

连续两轮超限项一致：

| Renderer | 第一轮关键值 | 第二轮关键值 | 判断 |
| --- | --- | --- | --- |
| Vega-Lite | Long Task 384ms，lag 427ms | Long Task 365ms，lag 402ms | 渲染 48 个 SVG 的集中主线程负载，分页 |
| Infographic | median 4.56s，P95 4.57s | median 4.54s，P95 4.56s | 233 个 SVG 的总完成时间超限，分页 |
| DrawIO | Long Task 396ms，lag 403ms | Long Task 366ms，lag 371ms | 59 个 SVG 的集中解码负载，分页 |
| WaveDrom | Long Task 563ms，lag 602ms，DOM 52,056 | Long Task 489ms，lag 544ms，DOM 52,056 | 主线程与 DOM 同时超限，分页 |
| D2 | median 1.63s，Long Task 498ms，DOM 421 | median 1.61s，Long Task 492ms，DOM 421 | 仅生成 2 个 SVG，主要是 renderer 初始化固定成本 |

D2 额外按 25 条拆成两页复测后，两页 Long Task 仍分别为 517ms、519ms，DOM 仅 302/378；分页没有降低固定初始化成本，因此保持一个文件，避免无效碎片化。

其余 renderer 两轮均未触发告警线，保持一个 Markdown。

## 固化配置与复测

最终固定容量：

```json
{
  "vega-lite": 24,
  "infographic": 60,
  "drawio": 30,
  "wavedrom": 12
}
```

最终 12 个分页页的 5 次复测全部无告警：

- median ready：902～1,530ms；P95：904～1,746ms；
- 最大 Long Task：198ms；
- 最大 event-loop lag：217ms；
- 最大 DOM：14,457；
- 检测到的渲染错误：0。

隐藏截图复核了 DrawIO、Infographic 等重型页的首屏和页尾；标题、正文、图表及文件树均无空白或横向溢出。

## 结论

- gallery Markdown 从 r2 的 124 个降至 r3/r4 的 27 个；
- 15 个 renderer 保持一个文件，仅 4 个有实测依据的 renderer 分页；r4 只增加导航与使用说明，不改变案例负载和固定分页容量；
- r4 正式 ZIP 共 112 个条目、405,583 B，仍包含 978 个案例和 65 个配套资源；
- benchmark 只产出 `.tmp/chart-examples-single-renderer.zip` 和 Playwright 测试产物，不影响正式 ZIP 的可复现性。
